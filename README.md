# Banjo-Kazooie VR

Banjo-Kazooie in VR, built on Lighthouse. Full stereo, first person & the diorama view.

Install it through the [Multiverse VR Hub](https://github.com/RaYRoD-TV/MVRH). One exe, it pulls the official Lighthouse release & applies my patch. Bring your own ROM.

No builds hosted here anymore. It all lives in the hub now, source too.
